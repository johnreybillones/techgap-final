# TechGap System Requirements

This documentation defines the required behavior, outputs, boundaries, and quality expectations of TechGap. It is based on the faculty and student evaluation questionnaires, aligned with Chapter 1, and incorporates the user's scope clarifications and combined Faculty/Academic Administrator user group.

## Confirmed scope

- Full Chapter 1 scope, including curriculum-change simulation and continuous job-market acquisition and updates.
- Official specialization-track and common/core computing courses for CICS BSCS and BSIT; General Education remains excluded from skill matching.
- Student and Faculty/Academic Administrator experiences accessed through role selection, without sign-in.
- Faculty members/professors, department chairs, associate dean, and dean belong to one Faculty/Academic Administrator system user group.
- User selections retained between visits.
- Evaluation questionnaires administered outside TechGap.
- Quality expectations stated in the questionnaires, without additional numerical response-time limits, device/browser commitments, capacity targets, or passing-rating thresholds.

The specification describes what the system must provide. Architecture, implementation technologies, algorithm selection, formulas, and storage design belong to subsequent work.
