# JobStreet browser automation research (2026-10-24)

## Assessment

**Technically feasible, but no-go for Chrome scraping now under the current documented terms.** The user confirmed prior JobStreet automation but did not provide or establish a written SEEK grant covering the proposed Chrome route. Prior automation and user authorization do not establish SEEK's prior written consent or make the activity low risk. If SEEK later supplies an explicit grant or authorized interface, re-evaluate its scope and run only a bounded evidence test before scaling.

JobStreet Philippines' current public results page exposes a `Next` link, and following it reaches `https://ph.jobstreet.com/jobs?page=2`. This demonstrates that browser navigation across at least one results-page boundary is technically available. It does **not** establish that all matching jobs are accessible, that every search has only two pages, or that traversing results would improve unique or assessable Game Development yield. [JobStreet Philippines results](https://ph.jobstreet.com/jobs), [page 2](https://ph.jobstreet.com/jobs?page=2) (accessed 2026-10-24, Asia/Manila).

Playwright officially supports Google Chrome and documents opening pages, navigating to URLs, and clicking page elements. Thus Chrome automation is mechanically feasible; that says nothing about authorization or collection completeness. [Playwright browsers](https://playwright.dev/docs/browsers), [Playwright pages](https://playwright.dev/docs/pages) (accessed 2026-10-24, Asia/Manila).

## Platform conditions and alternative

The current Philippines-hosted JobStreet Website Terms say: clause 7(d) prohibits data mining, robots, screen scraping, or similar automated gathering/extraction tools absent prior written consent. Clause 9(b) says automated processes, scripts, bots, scrapers, or other technical means must not access, query, search, copy, collect, mine, or harvest information unless SEEK provides a specific technical interface (such as an API) and its terms are followed. Clauses 9(d)–(e) permit technical detection/prevention measures and allow access limits or suspension for usage outside fair use or posing security/operational risk. Clause 9(c) concerns Profile data specifically. These published conditions indicate material operational and contractual risk absent a grant that clearly covers the proposed activity. [JobStreet Philippines Website Terms, clauses 7(d), 9(b)–(e)](https://ph.jobstreet.com/terms) (accessed 2026-10-24, Asia/Manila; terms state last updated 20 July 2026).

SEEK's developer documentation states that its API does not offer programmatic job-search capabilities. The documented job-ad reflection scenario is for authorized hirers to retrieve their own posted ads, so this API is not an obvious general job-search alternative. [SEEK Developer: Reflecting job ads](https://developer.seek.com/use-cases/job-posting/reflecting-job-ads) (accessed 2026-10-24, Asia/Manila).

A robots.txt policy was not verified in this review. Its status remains unknown and does not change the published terms above. Pagination and improved new assessable Game Development yield remain unproven. Re-evaluate only if SEEK later supplies an explicit grant or authorized interface, and begin with a bounded evidence test before any scaling. This note reports platform terms and technical documentation; it makes no legal conclusion and is not legal advice.


## Specific extension: Jobstreet Jobs Extractor

The supplied Web Store ID resolves to **Jobstreet Jobs Extractor**, offered by **Will Twitty**. The listing currently shows **13 users**, **no ratings**, version 1.0.0, updated June 4, 2026. It claims support for JobStreet Philippines and other listed country sites; bulk export of up to 10,000 jobs per task; CSV, Excel, or JSON; and fields including full job descriptions. These are listing claims, not independently verified performance. [Chrome Web Store listing](https://chromewebstore.google.com/detail/jobstreet-jobs-extractor/lkdefmkocmbfgphnffpjjhmimmemkpga) (accessed 2026-10-24, Asia/Manila).

The developer's site says to paste a JobStreet search-results URL, set an export count, and export; its pricing page advertises a free cap of 10 jobs and a $9.99/month Pro tier described as unlimited. Its FAQ lists title, company, apply URL, location, salary when listed, and posting date, but does not document pagination behavior or independently substantiate the Store's full-description/10,000-per-task claims. [Developer product page](https://jobstreet-scraper.niomaker.com/), [pricing and FAQ](https://jobstreet-scraper.niomaker.com/pricing/) (accessed 2026-10-24, Asia/Manila).

The Store says the developer disclosed that it does not collect or use data and says export data is stored locally; the listing does not expose the extension's detailed permission list in the reviewed page. Its linked privacy policy is a general NioMaker policy, says it does not apply to information customers process through its services, and describes account/device/usage collection and analytics for NioMaker services. These are provider disclosures; this review did not inspect extension code or runtime traffic and cannot independently verify data handling or least-privilege behavior. [Store privacy disclosure](https://chromewebstore.google.com/detail/jobstreet-jobs-extractor/lkdefmkocmbfgphnffpjjhmimmemkpga), [linked privacy policy](https://jobstreet-scraper.niomaker.com/privacy/) (accessed 2026-10-24, Asia/Manila).

Using this extension as described would still automate fetching and exporting JobStreet listings, which falls within the activities restricted by the current Philippines terms absent applicable written consent or a specifically authorized interface. Store presence and the developer's “use responsibly” disclaimer do not constitute SEEK authorization. Exporting more rows could make visible listings easier to collect, but it does not demonstrate less duplication, access to all matching jobs, or more new assessable Game Development postings; those outcomes remain unproven. The existing no-go recommendation therefore applies to this extension too.
