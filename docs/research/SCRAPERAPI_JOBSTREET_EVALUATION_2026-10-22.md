# ScraperAPI for the Philippine job collection: provider evidence

Retrieved 2026-10-22. This is a desk review of current ScraperAPI documentation and pricing, not an account-specific offer, live JobStreet test, cost quotation, or verified collection result.

## Decision-relevant summary

ScraperAPI is a general web retrieval service, not a documented JobStreet collection actor. Its ordinary API returns target-page HTML; its documented structured *jobs* endpoint parses **Google Jobs**, not JobStreet. Its optional AI Parser can attempt custom structured extraction from other sites but has no demonstrated JobStreet-specific completeness in the documentation. Crawler and asynchronous modes can retrieve or follow many URLs, but they do not establish that Philippine JobStreet search pages expose deeper, distinct results or that the resulting descriptions and dates meet TechGap admission requirements. The limiting metric remains **new, source-verifiable, eligible postings per credit**, not successful HTTP responses. [ScraperAPI API overview](https://docs.scraperapi.com/), [structured endpoint overview](https://docs.scraperapi.com/structured-data-endpoints/overview), [Google Jobs endpoint](https://docs.scraperapi.com/structured-data-endpoints/search-and-insights/google/google-jobs-api), [DataPipeline output formats and AI Parser](https://docs.scraperapi.com/data-pipeline/creating-a-datapipeline-project/results-and-output-formats), [crawler overview](https://docs.scraperapi.com/scraperapi-crawler-v2.0).

## Credit and performance mechanics

- A normal page request is listed at 1 credit; Google/Bing at 25; listed anti-bot bypasses at 10. JavaScript rendering is 10, residential/premium is 10, and premium plus rendering is 25; ultra premium plus rendering is 75. Site-specific and parameter costs require the provider's authenticated domain cost estimator or `/account/urlcost`; `sa-credit-cost` reports the resulting charge. The guide says successful HTTP 200/404 responses and requests cancelled before the provider finishes can be billed, whereas failed requests are not. A 200 response still needs content validation. [Credit cost guide](https://docs.scraperapi.com/getting-started/quick-start/credits-and-requests-costs), [API status codes](https://docs.scraperapi.com/responses-and-formats/api-status-codes).
- Illustratively, 5,000 trial credits equal at most 5,000 one-credit pages, 500 ten-credit pages, 200 25-credit pages, or 66 75-credit pages, before any other restrictions. Those are arithmetic ceilings, **not** predicted successful JobStreet pages or postings. The actual JobStreet cost is unknown without the account/domain estimator. [Credit cost guide](https://docs.scraperapi.com/getting-started/quick-start/credits-and-requests-costs).
- A request can set `max_cost`, and the provider says it rejects an over-limit request with HTTP 403. This caps a request, not the campaign's total spend. Free/paid plan concurrency and overage rules also matter. [Sync API overview](https://docs.scraperapi.com/synchronous-apis/overview), [pricing FAQ](https://www.scraperapi.com/pricing/).
- ScraperAPI says a typical synchronous result arrives in seconds, but difficult domains can take up to about 60 seconds; it recommends a 70-second client timeout. It says 1–3% of requests can fail across its traffic. Its async service can retry for up to 24 hours, then retains results for a limited time. These are provider-level statements, with no JobStreet-specific Philippine success, latency, eligible-yield, or completeness measurement. [Sync API overview](https://docs.scraperapi.com/synchronous-apis/overview), [general FAQ](https://docs.scraperapi.com/resources/faq/general), [async overview](https://docs.scraperapi.com/asynchronous-api/overview).
- Rendering uses Chromium, can wait for a selector, and has a higher credit cost. ScraperAPI explicitly warns that rendering raises latency and may reduce success rates. The pricing page's 99.9% uptime guarantee concerns the service; ScraperAPI's own guide says broad success claims lacking target, window, retry policy, and content checks do not establish reliable target data. [JS rendering](https://docs.scraperapi.com/resources/faq/js-rendering), [pricing](https://www.scraperapi.com/pricing/), [ScraperAPI's reliability guide](https://www.scraperapi.com/quick-start-guides/web-scraping-success-rates-how-to-read-reliability-claims/).

## Compatibility with the TechGap collection

| Path | What provider documents | Gap to verify |
| --- | --- | --- |
| JobStreet page via normal or async API | Accept a target URL and return HTML; the API can also fetch public API URLs. Parameters support rendering, selectors, headers, proxy options, and device type. DataPipeline's built-in autoparse is documented for Amazon, eBay, Google, Redfin, and Walmart; its AI Parser can be tried for other domains. The docs do not demonstrate this target or completeness across search pages. AI parsing cannot be assumed to fix missing source content or find all postings. |
| Crawler | Discovers linked pages, skips duplicate URLs, and has depth/credit controls; paginated search is a listed use case. [Crawler overview](https://docs.scraperapi.com/scraperapi-crawler-v2.0). | Following links does not prove that a JobStreet search exposes all relevant postings, that pages beyond the first are accessible, or that employer-side duplicates are resolved. These are admission-critical fields and must be checked on actual responses before use. The listed TLD choices do not include `com.ph`; the endpoint's country setting and Google result localization would need empirical validation. |

For raw JobStreet URL retrieval, ScraperAPI lists Philippine `country_code=ph` proxy targeting only on Business or higher plans; Hobby and Startup allow only US/EU regional targeting. A Philippine destination URL is not itself evidence of a Philippine exit IP. The trial's and Education plan's access to this feature is not established by the pricing/docs reviewed. [Standard geotargeting](https://docs.scraperapi.com/control-and-optimization/geotargeting/standard-geo), [pricing](https://www.scraperapi.com/pricing/), [academic research offer](https://www.scraperapi.com/web-scraping-for-academic-research/).

ScraperAPI's troubleshooting guide says to check the target site's scraping permissions and limits support to publicly available pages. Use of this intermediary does not change target access terms or confer reuse rights for posting text. [Low success rates and allowed URLs](https://docs.scraperapi.com/resources/faq/low-success-rates).

## Evidence gaps and bounded comparison

The official material does **not** verify that ScraperAPI would produce more distinct Philippine entry/junior ads, fewer unresolved records, deeper JobStreet pagination, or a lower cost per accepted posting than the saved Apify campaign. A future, permitted pilot could compare identical query/date windows and record: target HTTP and content validity, unique source IDs, exact posting dates, complete requirements, eligible employment and internship cohorts, track/role mix, overlap with the existing registry, credits consumed per request, and cost per **new accepted** posting. The free trial may be useful for that limited experiment; no provider claim supports a migration or larger budget commitment yet.
